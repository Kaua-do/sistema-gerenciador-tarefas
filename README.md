# 📋 Sistema de Gerenciamento de Tarefas

Sistema de gerenciamento de tarefas desenvolvido em Python utilizando Programação Orientada a Objetos, persistência em JSON, autenticação de usuários e interface no terminal com Rich.

## 🚀 Funcionalidades

- ✅ Cadastro e login de usuários
- 🔐 Senhas protegidas com bcrypt
- 📌 Criar tarefas
- ✏️ Editar tarefas
- 🗑️ Remover tarefas
- ✅ Concluir tarefas
- 📅 Definir prazo
- ⚠️ Detectar tarefas vencidas
- 🔎 Buscar tarefas por título
- 📊 Dashboard de produtividade
- 🎯 Filtro por prioridade
- 📂 Exportação de tarefas
- 📝 Sistema de logs
- 🧪 Testes automatizados com pytest

## 🛠️ Tecnologias utilizadas

- Python 3
- Rich
- Pytest
- Bcrypt
- JSON
- Programação Orientada a Objetos (POO)

## ▶️ Como executar

Clone o projeto:

```bash
git clone URL_DO_REPOSITORIO
```

Entre na pasta:

```bash
cd sistema-gerenciador-tarefas
```

Instale dependências:

```bash
pip install -r requirements.txt
```

Execute:

```bash
python main.py
```

## 🧪 Rodando testes

```bash
pytest
```
